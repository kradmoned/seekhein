# Sum Positive Numbers

Implement `sum_positive(numbers)`, which returns the sum of the integers
strictly greater than zero in a list.

## Requirements

- Keep the function name `sum_positive` and its `numbers` parameter.
- Include only positive integers in the sum; ignore negative integers and zero.
- Return `0` if the list is empty or contains no positive numbers.
- Do not modify the input list.
- Return the answer instead of printing it.
- You can assume every item is an integer. No third-party packages are needed.

## Examples

```python
sum_positive([2, -3, 5, 0])  # returns 7
sum_positive([-4, 0])       # returns 0
sum_positive([])            # returns 0
```

Complete the function in the editor and use **Run code** to check your work.
